# 📡 FreeTools-App

> 🛠️ 25 free Python utility tools: system info, file manager, network scanner, password generator, QR code, weather, and more. Rich CLI menu included.

---

## ✨ Features

- ✔ **Advanced security scanning**
- ✔ **Real-time monitoring and alerts**
- ✔ **Multiple security tools integrated**
- ✔ Lightweight and optimized
- ✔ Cross-platform compatibility
- ✔ Regular updates

---

## 💻 Tech Stack

| Component | Technology |
|-----------|-----------|
| Language | Python |
| UI | CustomTkinter / PyQt |
| Platform | Windows / Linux / macOS |

---

## 🚀 Installation

```bash
git clone https://github.com/zougar99/FreeTools-App.git
cd FreeTools-App
pip install -r requirements.txt
```

---

## 🧰 Usage

```bash
python main.py
```
